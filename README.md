# 沧海纪 (Age of Tides)

原创设定的大航海贸易 + 海域争霸单机游戏，灵感来自「大航海时代」系列的玩法框架（贸易、船队、海域份额、海战），
但所有地名、势力、剧情、美术均为原创，不含任何 Koei 版权内容。

## 运行

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # 产物在 dist/
```

`legacy/index.html` 是第一版的单文件实现（纯 HTML/SVG，无依赖），直接双击可玩，保留作参考。

### 经济模型重做（堵死刷钱回路）

玩家发现「加的斯 ⇄ 塞维利亚 来回倒瓷器可以无限刷钱」。根因不在这两个港口，而在价格模型本身：成交价按**成交前**的库存指数计算，但买入会推高库存指数——于是「买完立刻卖」就能吃到自己刚推上去的价格，而且议价加成叠满后买价还会低于卖价。审计显示 **960 个「港口 × 商品」组合全部可以原地刷钱**，威尼斯买满一船珠宝再原地卖掉净赚 11 万金币，一天都不用走。

现在的模型有三条铁律（`game.js`）：

1. **买卖价永远有价差**。`buyPrice = 挂牌价 × (1 + 6%×(1−议价优势))`，`sellPrice` 对称向下；海域主导、船长特性、声望只能把价差**收窄最多 60%**，永远合不拢。原地买了再卖必然亏约 10%。
2. **成交价沿成交量积分**。买得越多均价越高、卖得越多均价越低，交易必须自己承担价格冲击，而不是把冲击留给下一个人。
3. **积分取中点**，拆成 10 个小单和一次买满结果完全一致，杜绝「切小单规避冲击」。

配套改动：价格冲击改为**每天回落 1.4%**（原本挤在月结，可以卡月底钻空子）；市场表直接标出「行情↑18%（近期成交所致）」与「买满 29 件均价 37（+9%）」，让因果可见。

同一次审计还查出另外三类白嫖，一并修掉：

| 漏洞 | 成因 | 修法 |
|---|---|---|
| 运货委托白拿货 | 接单时委托方把货装船，弃单只加一个计数器 | 托运货标记为不可变卖；违约时货主收回实物、短少部分照价赔偿并付违约金；新增「放弃委托」按钮 |
| 采购委托就地交差 | 报酬按本地行情的 1.25–1.6 倍计，而货就在本地卖 | 只收本港**紧缺**货（本地价 ≥1.7 倍基准价），报酬改按基准价的 1.25–1.55 倍计，就地现买必然亏本 |
| 委托过期不结算 | 只在靠港时检查时限 | 每过一天检查一次 |

`tools/economy_audit.mjs` 把这套审计固化下来，直接跑 `game.js` 的真实买卖代码路径，枚举全部 780 个港口对 × 24 种商品的对冲回路与原地回路，发现刷钱就以退出码 1 失败。

```bash
node tools/economy_audit.mjs --all
```

### 其他体验优化

### 画面质感升级

玩家反馈「房子和船像 90 年代的画质」。问题不在于用像素画，而在于craft：船是 16×16 的平涂剪影，房子是加了窗格的矩形，地图是一整片平涂绿。这轮全部重画，并新增 `art.js` 作为三个场景共用的美术工具箱——同一套光照方向（左上）、同一套明暗/饱和/大气透视函数、Bayer 抖动、值噪声与山脊噪声、距离场。有了共同的底座，海图、港口与船的质感才会是一致的。

**世界地图**（`pixelart.js: makeWorldLandCanvas`）
- 先在导航栅格上求两个距离场——陆地格到最近海、海格到最近陆地——据此生成高程：海岸低、内陆高，叠加 fbm 与山脊噪声形成连绵山脉而非圆丘。
- 按纬度分气候带上色（冰原 / 苔原 / 针叶林 / 温带 / 地中海 / 荒漠 / 稀树草原 / 热带雨林），再用湿度噪声与副热带高压带、季风亚洲的经验偏置打散，所以撒哈拉是沙、刚果是林、斯堪的纳维亚是针叶林。高海拔转岩色，雪线随纬度上移。
- 山体阴影按左上光源逐格计算，再逐像素双线性插值，所以起伏是连续的而不是方块。
- 海侧铺一层由深到浅的大陆架（距岸 15 格内的 alpha 渐变），深海留给会动的水面平铺层。整张 3180×1596 的陆地层生成耗时约 100 ms。

**船只**（16×16 → 32×32）
- 船体分甲板受光线、船身、近水线转暗、水线四层；艉楼、舷侧饰带、炮门、艏斜桁。
- 帆分横帆与三角纵帆两种画法：帆桁 + 鼓起的帆面，左受光、右背光、后缘最暗，中间一道缩帆索。索具从桅顶拉向艏艉。
- 艏浪与艉迹。正面 / 背面视角单独画，不再复用侧视图。

**港口场景**（`port.js`）
- 内部分辨率 320×200 → 480×300，才画得下屋檐、窗台、招牌。
- 从远到近五层：抖动渐变的天空与太阳辉光 → 两道带雪顶的远山（大气透视褪色）→ 缓坡田野 → 中景城镇剪影（坡屋顶 / 尖塔 / 穹顶，起伏的天际线）→ 城墙与拱券门洞 → 主街四栋建筑 → 透视石板路 → 码头与系缆桩 → 带建筑倒影的海面 → 前景木箱、酒桶、缆绳。
- 每栋建筑统一光照：左受光墙 → 右背光墙的横向渐变、底部环境遮蔽、檐下阴影、右下方地面投影；窗是内凹的（上沿暗、右内壁反光、窗台受光 + 投影 + 百叶），门有拱券、台阶与门灯。屋顶按地域分五种做法（坡屋顶 / 陡坡 / 翘角 / 茅草 / 穹顶 / 女儿墙），全部是脊窄檐宽的正确形态。
- 四栋建筑高度错落、前后进退，并挂上各自的招牌（酒杯 / 天平 / 锚 / 官印）。

**航行视角**（参考《大航海时代》的航行画面）
- 出航即把镜头平滑推到 1.9×（`SAIL_ZOOM`）并跟住船队，抵港后回落到 1.15×。工具栏新增「⛵ 航行视角」按钮与倍率读数；手动缩放会立刻取消自动推镜并保持你选的倍率。
- 船不再是恒定屏幕尺寸的图标，而是**世界里的实体**：玩家船与 NPC 船都按世界比例绘制，拉近变大、拉远变小，海面与海岸线的比例关系才成立。玩家船在航行视角下约 47 px，三级大港图标约 38 px。
- 港口是地图符号，用「部分反向缩放」（`(1/zoom)^0.6`）：拉近时跟着世界一起变大，拉远到全图时也不至于消失；港口名与海域名仍保持可读的固定字号。
- 最大缩放 2.4× → 3.4×；尾流点随船一起按世界比例放大。

**海面**：16×16 四帧 → 32×32 六帧，用整数频率的正弦叠加做涌浪（保证无缝平铺），波光逐帧右移且循环闭合。

**港口图标**：单一通用小房子 → 按海域风格上色、按规模决定建筑数量与有无塔楼的小码头，海图上一眼能看出这是什么样的港。

### 清晰度、全球视角与帧率

三个反馈：画面不够精细、全球地图上船只和城市互相重叠、想要更高帧率。逐条查下来是三个独立的问题。

**锯齿与糊：渲染分辨率没跟上设备像素比。** Pixi 初始化时写的是 `resolution: 1, autoDensity: false`，而 Retina 屏的 `devicePixelRatio` 是 2——画布后备像素只有显示尺寸的一半，整个游戏被浏览器拉伸 2× 再平滑。改成 `resolution = min(2, DPR)` + `autoDensity` 后画布从 584×753 变成 1168×1506，文字、立绘、像素贴图全部变清晰。同时开了 `antialias`，让航线、势力环、六角格这些矢量图形的边缘不再毛糙。

**像素块忽宽忽窄：缩放不是整数倍。** 缩放 1.9 × DPR 2 = 每个逻辑像素 3.8 个物理像素，最近邻采样下有的像素占 3 格、有的占 4 格，移动时就是抖动和锯齿。现在缩放会吸附到「一个逻辑像素正好等于整数个物理像素」的档位（`snapZoom`）：≥1 时按 1/RES 步进，<1 时按整数倍缩小。航行视角随之从 1.9× 改为 2×。

**海岸线的台阶：画面层沿用了寻路网格。** 陆地层原先按导航网格（4 逻辑单位 ≈ 0.33°）逐格填色，所以海岸线是 4 像素一级的台阶——这跟输出分辨率无关，是源头就粗。现在把「场」和「掩膜」分开：地形起伏、气候带、浅滩这些连续量仍按粗网格算再双线性插值，而陆海边界改用 1 逻辑单位/像素的高分辨率掩膜（`nav.buildHiMask()`）逐像素判断，海岸线细了 4 倍，沙滩宽度也按真实离岸距离分三档。生成耗时 100 ms → 279 ms，仍是一次性加载开销。

**全球视角的重叠：加了 LOD 与标签避让。**
- 缩放低于 0.75× 时，港口从详细的小码头切换为带描边的菱形地图符号（规模决定大小，大港带小旗），并保持约 14 px 的固定屏幕尺寸——既点得到，又不会糊成一片。
- 缩放低于 0.7× 时不绘制 NPC 船队：全球视角下 46 条船只会和港口挤在一起。
- 势力色环在低缩放下只画给「你主导的海域」和当前港 / 目的港，造船厂等级方块隐藏。
- 港口名与海域名做屏幕空间避让：按优先级（当前港 → 目的地 → 任务港 → 规模）依次占位，与已放下的标签重叠的直接不显示，用的是文本真实尺寸而非字数估算。全球视角下 40 个港口只显示 9 个名字，海域名显示 8 个，不再堆叠。

**帧率**：Pixi 的 ticker 本来就没有上限（`maxFPS = 0`），跟着显示器刷新率走，所以没有「帧数上限」可以解开。真正能做的是降低每帧开销，抵消分辨率翻倍的成本：航线重绘与弹窗查询从每帧改为约 8 次/秒，`updateBanner`／标签避让／昼夜同样降频，低缩放下直接跳过 NPC 渲染。工具栏加了实时帧率读数，可以直接看自己机器上的真实帧率（低于 50 变黄、低于 30 变红）。

## 玩法

- **目标**：在西洋 / 北海 / 东海 / 南洋 / 珍珠海 / 黄金海六大海域取得 ≥50% 势力份额。
- **船长**：开局三选一（林远舟 贸易 −5% 买价 / 沈鹭 航速 +1 / 哈迪·铁山 炮击 +20%）。
- **贸易**：16 种商品、18 个港口，每港有「特产」（≈55% 基准价）与「紧缺」（≈170% 基准价）。买卖会影响当地价格，跨月恢复。
- **事件**：风暴、海盗、顺风、漂流物、热病、遭遇对手商会船队（可选择攻击）。
- **势力份额**：投资港口 / 在海域卖货 / 击败对手船队 提升份额；主导海域有月收益与进货折扣。三家对手商会每月自动扩张。
- **船队**：5 种船型，造船厂买船 / 修理 / 装炮，酒馆招募船员 / 打听情报 / 停泊休整。船队上限 6 艘。
- **海战**：六角格战术回合制，每船每回合移动 + 行动；炮击（火炮，随距离衰减）/ 接舷（船员，可俘获）/ 撤退（航速与距离）。全灭后被救起，失去货物与半数金币。
- **人物**：港口四位 NPC 按场景说话；事件由大副阿海播报；海盗头目与三家商会代表在遭遇和海战中登场。画像为程序化 SVG。
- **剧情任务**：序章 → 11 章主线 → 两场决战；14 个支线；任务页签查看进度，海图 ★ 与街景 ! / ? 标记指路。
- **存档**：抵港自动保存、航行中每 10 秒自动保存（localStorage 键 `aot-save-v2`）。
