# 沧海纪 (Age of Tides)

原创设定的大航海贸易 + 海域争霸单机游戏，灵感来自「大航海时代」系列的玩法框架（贸易、船队、海域份额、海战），
但所有地名、势力、剧情、美术均为原创，不含任何 Koei 版权内容。

## 运行

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # 产物在 dist/
```

`legacy/index.html` 是第一版的单文件实现（纯 HTML/SVG，无依赖），直接双击可玩，保留作参考。

## 当前阶段：六步路线图 + 剧情任务 + 真实世界地图

- Vite + PixiJS 8 渲染层，游戏逻辑与表现层解耦（`game.js` 通过 `hooks` 调用 UI）。
- 像素风海图：4 帧循环的平铺海面（双层错位滚动）、由 SVG 路径栅格化出的像素陆地（草地 / 沙岸 / 浅滩 / 树木）、像素港口图标、16×16 船精灵（东 / 北 / 南 + 镜像，2 帧颠簸）。
- 实时航行：点击港口出航后船在海上逐帧移动，日期按里程推进（1 天 = 船队航速 × 10 逻辑单位），途中可点其他港口改航向；航程中点触发随机事件（弹窗期间世界暂停）。
- 航迹粒子、昼夜色调遮罩、镜头跟随 / 拖动 / 回中、1× / 3× 快进。
- 所有像素贴图在运行时由代码生成（`pixelart.js`），替换成真 PNG 只需改加载函数。

### 第 2 步「UI 换皮」

- 九宫格像素边框：`style.css` 里两张内联 SVG（金 / 钢）通过 `border-image` 切九宫，套在弹窗、侧栏、卡片、对话窗上。
- 字体：数字与拉丁字母用 Press Start 2P（Google Fonts，离线时回退系统字体），中文用系统字体 + 硬阴影；标题带 ◆ / ◇ 装饰。
- 打字机对话窗（`fx.js`）：事件、情报、遭遇台词逐字出现，标点停顿，光标 ▌ 闪烁，说完出现 ▼，点击或回车可跳过；打完前操作按钮隐藏。
- 光标式菜单：弹窗内方向键 / Tab 移动 ▶ 光标，回车确认，Esc 取消；鼠标悬停同步光标；数字键 1–4 切换侧栏页签。
- 金币变化数字滚动 + 飘字，出航 / 抵港黑场闪切，海图叠一层 CRT 扫描线。

### 第 3 步「港口场景」

- 停泊时海图区域切换为像素街景（`port.js`），出海时切回海图；右上角「⛵ 出海 · 海图」/「⚓ 回港」切换，点码头上的船也能出海。抵港自动进入街景。
- 街景按整数倍放大（保证像素整齐），随窗口尺寸重建；布局以港口 id 为种子，每港固定且各不相同。
- 六大海域各一套建筑风格：西洋木筋墙红瓦人字顶、北海深木板灰石陡顶、东海白墙翘檐、南洋土墙茅草配棕榈、珍珠海白墙圆顶、黄金海石墙金边平顶。
- 四栋功能建筑是热区：货栈 → 市场、酒馆 → 酒馆、港务府 → 投资、造船厂 → 造船厂。悬停金框高亮 + 名字变金，点击直接切到侧栏对应页。
- 动画：2 帧路人步行循环（随机停步）、3 帧海鸥、3 帧海域色旗子、酒馆烟囱冒烟、码头浪花、飘云、船身起伏、夜晚窗灯；天空按时刻叠加暖色（晨昏）与深蓝（夜）。

### 第 4 步「人物立绘」

- `portraits.js` 新增 `bust(c, w)`：4:5 半身立绘（背景光斑与斜纹、肩膀与服装、颈、头、发、眼白/虹膜/瞳孔/高光、腮红、下巴阴影、胡须、帽子、饰品）。六种服装版式：大衣（翻领 + 纽扣）、制服（肩章 + 绶带 + 勋章）、长袍（交领 + 腰带）、马甲（衬衫 + 背心，可加弹药带）、连衣裙（领口 + 披肩 + 胸针）、围裙。角色的 `outfit` / `inner` / `trim` / `eyes` / `strap` 在 `data.js` 里配置。
- 两层嘴部：`.m-closed` / `.m-open` 同时画在 SVG 里，打字机每 3 个字切换一次 `talk` 类，说完闭口。眼睑层 `.lids` 用 CSS 关键帧周期眨眼，每个角色相位不同。
- 立绘用在事件对话、酒馆情报、遭遇商会、船长选择（三张错峰滑入）、海战对峙（敌方水平镜像，面对面）、船队页船长卡。紧凑的港口 NPC 卡和顶栏仍用小圆头像。

### 第 5 步「六角格海战」

- `battle.js`：12×8 尖顶六角格（odd-r 偏移坐标，立方坐标算距离），战斗在海图区域展开，侧栏变成 HUD（船长对峙立绘、回合数、我方船列表、当前船操作、战斗日志、结算）。
- 规则：每回合每艘船可移动一次（`ceil(航速/2)` 格，BFS 可达范围，绿色高亮）+ 行动一次（炮击 / 接舷 / 待机）。射程 3 格（红圈标出），距离 1/2/3 格伤害 100%/85%/70%；接舷需相邻，船员归零即俘获。撤退成功率 = 原公式 + 每远离敌船 1 格 +10%。
- 敌方 AI：逐船向最近目标逼近，进入射程即开炮；相邻且我方船员薄弱（或己方船员占优）时改为接舷。
- 特效：炮口闪光、炮弹抛物线、命中烟雾 + 木屑（带重力与旋转）+ 白色闪光、受击船体闪红、伤害飘字、屏幕微震、接舷时船身前冲 + 三道白色刀光、沉没时下沉 / 倾斜 / 渐隐 + 气泡、移动时航迹粒子。
- `game.js` 改为单目标结算 `fireAt()` / `boardAt()`，旧的列表式回合战已移除；`endBattle()` 结算（战利品、份额、全灭救援）沿用。

### 第 6 步「音乐音效与天气」

- `audio.js`：Web Audio 运行时合成，无任何外部音频素材。三段原创 chiptune 循环（海图 6/8 拍琶音、港口 4/4 拍轻快、战斗小调快节奏带鼓），按场景模式自动切换并交叉淡入淡出；音效：按键、开窗、打字、金币、付款、炮击、命中、接舷、沉没、出航、抵港钟声、雷声、胜利 / 失败。首次点击或按键后才创建 AudioContext（浏览器自动播放策略）。顶栏「🔊 音效 / 🔇 静音」切换并持久化。
- `weather.js` + `game.js` 天气状态：航行中每天结算，10% 起雨（2–3 天）、4% 起风暴（1–2 天），风暴事件也会带来风暴天气。雨天：雨丝、暗调、雨声、航速 ×0.9；风暴：更密的雨、海面加速、周期闪电 + 雷声 + 屏幕抖动、航速 ×0.72。天气延续到港口街景；横幅与顶栏显示 ☀ / 🌧 / ⛈。

### 第 7 步「剧情与任务」

- `story.js`：原创剧情《沧海纪·海不分家》——玩家继承老船主的初雪号与被撕去最后一页的账本，追查「护航费」与三家商会「分海约」的黑幕；11 章主线跨六大海域，含珊瑚镇（对赫克托旗舰）与龙骨岛骸湾（对独眼巴罗）两场剧本化决战，终章与主导海域机制挂钩；14 个支线分布在 12 个港口（运货、贸易、海战、探索、投资、造船）。新增原创 NPC 顾砚（前蓝鲸账房）、丁伯（龙骨岛灯塔守）。内容由三位叙事设计 Agent 并行产出、三位评审打分、合成后逐 id 校验。
- `quests.js` 任务引擎：前置（前置任务 / 天数 / 份额）→ 到港自动提供（主线直接接下，支线可婉拒，再次到访重提）→ 目标追踪（visit / visitZone / explore / sell / buy / deliver 自动扣货 / defeat / share / dominate / invest / gold / fleet / boss）→ 交付港或即时结算 → 奖励（金币 / 份额 / 赠船 / 火炮 / 船员）+ 结束对白。决战目标到港触发强化 BOSS 船队（旗舰 + 1.35× 护航），胜利即完成。
- 界面：新增「任务」页签（主线进度条、支线、线索、可交付提示）；海图上任务相关港口名前带 ★；港口街景中给任务的 NPC 建筑头顶有跳动的「!」（可接）/「?」（可交付）；多页立绘对话序列（接受 / 婉拒按钮、页码、打字机）。序章在选船长后播放；旧存档载入后也会补播。

### 第 8 步「真实世界地图 + 海上生态」

针对「海上看不到别的船 / 遇到 NPC 互动太少 / 地图不像真实世界 / 港口规模看不出来」四个问题的重做。

**真实世界地图**
- `geo.js`：等距圆柱投影（`x = (lon+180)/360`，`y = (90-lat)/180`），地图窗口西经 105° 到东经 160°、南纬 58° 到北纬 75°，1 经纬度 = 12 逻辑单位。海岸线为手绘简化多边形，全部用真实经纬度，包含五大洲与三十余个岛屿。
- `data.js`：40 个真实港口（里斯本、塞维利亚、伦敦、阿姆斯特丹、威尼斯、伊斯坦布尔、亚历山大、埃尔米纳、摩卡、果阿、卡利卡特、马六甲、广州、长崎、马尼拉、哈瓦那、卡塔赫纳、萨尔瓦多……），坐标为该城市真实经纬度；10 个真实海域；24 种时代真实贸易品（新增咸鱼、橄榄油、烟草、毛皮、玻璃、染料、武器、白银）。胜利条件改为主导 10 个海域中的 6 个。
- `nav.js`：把陆地栅格化成 0.33° 的导航网格，用 A* 做海上寻路并做视线平滑，所以里斯本去果阿会自动绕好望角、摩卡去卡利卡特会穿曼德海峡。直布罗陀、博斯普鲁斯、曼德、霍尔木兹、马六甲、巽他等窄于一格的海峡在栅格里强制打通。
- 航程按真实比例：里斯本→塞维利亚 2 天、→伦敦 5 天、→亚历山大 10 天、→哈瓦那 19 天、→果阿 42 天、→广州 54 天。补给消耗因此成为远洋航行的真实约束。
- 海图支持滚轮 / 按钮缩放与全图视角，图标与文字按缩放保持可读，低缩放时只显示大港标签。

**海上 NPC 船队**（`npc.js`）
- 全球同时有 46 支 NPC 船队在港口之间沿寻路航线实时航行：三家商会的商船队与护航舰队、自由商人、渔船、海盗。阵营按各海域的势力份额加权生成，所以谁控制了哪片海，海面上就能看出来。
- 精灵对象池 + 视口剔除，寻路请求分帧处理；NPC 不写入存档，读档时重新生成。
- 海盗会主动追击实力较弱的玩家船队；雇了护航则不会被袭击。

**遭遇多选项互动 + 声望**
- 「攻击 / 避开」扩展为按阵营、关系、实力比过滤的行动表：打招呼、海上交易（买对方的货，通常低于行情；海盗处可买赃物）、打听行情（记入航海志）、雇佣护航、索要通行费（你主导该海域时）、威慑劝降（实力碾压时不战而取）、交买路钱、发动攻击、脱离。
- `S.rep` 记录与蓝鲸 / 红帆 / 金沙 / 海盗的好感度（−100~100），影响进货价、遭遇可选项与对方是否主动攻击。势力页有声望条。

**港口信息可视化**
- 海图上港口图标大小 = 规模（小港 / 中港 / 大港），上方金色短条数 = 造船厂等级（▮▮▮ 可造盖伦与巡防舰），外圈颜色 = 该海域主导势力，灰暗 = 未到访，★ = 有任务或委托。
- 悬停港口弹出信息卡（海域、规模、造船厂、直线距离与天数、特产与紧缺）。
- 📖 港口名录：40 港总表，可按海域筛选，按距离 / 规模 / 造船厂 / 名称 / 所选商品利润排序，显示已知价与「每件每天利润」，点「前往」直接出航。买大船不用再一个城市一个城市试。
- 市场表新增「最佳去处（每件）」列，基于已到访与打听到的行情，给出目的地、单件利润、天数与每天收益。
- ？ 图例说明全部图标含义。

**其他优化**
- `contracts.js` 港口委托板：每港按「港口 + 时段」种子生成 2–4 个委托（运货 / 采购 / 剿匪 / 快航），每 20 天一批，有时限与报酬，完成还给海域份额。让 40 个港口每一个都有去的理由。
- 海图左上角常驻目标指引条，随时回答「现在该干什么」（补给不足 / 委托快到期 / 任务可交付 / 主线下一步 / 没事干时提示去名录或委托板）。
- 出航面板显示直线公里数、实际航程天数、目的地规模与造船厂等级。
- 顶栏显示主导海域进度。

## 玩法

- **目标**：在西洋 / 北海 / 东海 / 南洋 / 珍珠海 / 黄金海六大海域取得 ≥50% 势力份额。
- **船长**：开局三选一（林远舟 贸易 −5% 买价 / 沈鹭 航速 +1 / 哈迪·铁山 炮击 +20%）。
- **贸易**：16 种商品、18 个港口，每港有「特产」（≈55% 基准价）与「紧缺」（≈170% 基准价）。买卖会影响当地价格，跨月恢复。
- **事件**：风暴、海盗、顺风、漂流物、热病、遭遇对手商会船队（可选择攻击）。
- **势力份额**：投资港口 / 在海域卖货 / 击败对手船队 提升份额；主导海域有月收益与进货折扣。三家对手商会每月自动扩张。
- **船队**：5 种船型，造船厂买船 / 修理 / 装炮，酒馆招募船员 / 打听情报 / 停泊休整。船队上限 6 艘。
- **海战**：六角格战术回合制，每船每回合移动 + 行动；炮击（火炮，随距离衰减）/ 接舷（船员，可俘获）/ 撤退（航速与距离）。全灭后被救起，失去货物与半数金币。
- **人物**：港口四位 NPC 按场景说话；事件由大副阿海播报；海盗头目与三家商会代表在遭遇和海战中登场。画像为程序化 SVG。
- **剧情任务**：序章 → 11 章主线 → 两场决战；14 个支线；任务页签查看进度，海图 ★ 与街景 ! / ? 标记指路。
- **存档**：抵港自动保存、航行中每 10 秒自动保存（localStorage 键 `aot-save-v2`）。
